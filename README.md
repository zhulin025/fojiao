# 一叶 · 佛教脉络指南

以历史、宗派关系、地域传播和通俗概念串起佛教的知识网站。独立于上层目录的京都项目，仅在本地运行，未配置或执行线上部署。

## 本地运行

```bash
cd buddhism
npm ci
npm run dev
```

默认预览：http://127.0.0.1:5174/ 。生产构建：`npm run build`；本地构建预览：`npm run preview`。

## 网站内容与交互

- 40 篇导读、104 个正文小节，覆盖历史、宗派、地区、思想、经典、实践、艺术与文化。
- 三大体系关系导览；汉传八宗、日本主要宗派、藏传多派的对照说明。
- 7 个历史阶段、6 个地区专题与可点击的原创传播示意图。
- 全文搜索、分类筛选、相关文章、10 篇入门阅读路线。
- 收藏、手动标记已读、学习进度（浏览器 localStorage）。
- 8 张思想概念闪卡、5 道测验及答案解释。
- 桌面、平板、手机响应式布局，语义化 HTML、原生 dialog、Esc 关闭、键盘操作与减少动画偏好。
- 生产构建注册同源 Service Worker，缓存已访问资源；开发环境不启用缓存。

## 文件

- `src/main.jsx`：界面与交互。
- `src/data.js`：文章、参考来源、时间线、地区、题目。
- `src/Illustrations.jsx`：原创菩提树佛塔插画、宗派图标及传播示意图。
- `src/style.css`：视觉与响应式样式。
- `public/fonts/`：随站提供的 DM Sans 拉丁字体及 OFL 许可；中文使用系统宋体和黑体。

内容以通俗入门为目标，覆盖主要传统而非所有细分支派。每篇附参考入口，区分经典、学术机构与传统内部视角；历史年代有争议时采用约略描述。“小乘”作为历史术语解释，不作为当代上座部的默认名称。地图不表示精确疆界，插画不是文物复原。

没有账号、后端或跟踪分析。进度只存于当前浏览器；外部资料链接由用户点击后打开。
